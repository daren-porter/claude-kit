# Backlog

The living next-steps doc for the kit. Active items only; when an item is done it moves out to a dated snapshot in `archive/` (`backlog-YYYY-QN.md`) rather than being struck through in place. Per-effort history lives in each plan's Chapters, not here; this file is for cross-effort next steps that belong to no single open plan.

**Every active item states how it closes, and its title states the finding rather than an action.** A title reading as an imperative mis-sizes work whose body makes it conditional: on 2026-09-04 "Extract a shared plan-status helper" was recommended to the user as a straightforward refactor off its title, while the body's operative sentence made it contingent ("IF the classifier gains nuance ... single-source those three"). The condition had in fact already fired, so the work was justified by a defect the title never mentioned, which is the point. `test/backlog-closure.test.js` pins the closure clause and the dated title; the wording half is a convention no test can reach.
